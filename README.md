# Conference-Avery
AP CSA
Project Reflection: For the Conference project, We were given the task to help provide seating assignments for guests from varying companies at an event, mixing up guests between various companies and also allowing new guests to be registered on the day of the event (i.e. manually). The project also emphasized an aspect of user interface which would ensure easy usage of the program and readability. This project was really helpful in allowing me to familiarize myself with the versatility and flexibility which ArrayLists offer as well as the complex and time-consuming thinking process coding requires before any writing even starts. I found that writing the actual for loops and declaring the variables was a much easier process than deciding what combination of methods would be necessary to address every limitation of the Conference project (such as the max number of guests, companies, etc.) I also found myself working a lot on reflecting on each individual aspect of my project as a whole in my comments and also in the processes of creating my poster board for the CS Fair which this proejct will be presented at. Some of the biggest challenges I faced had more to do with the thinking aspect of the project rather than the actual coding. At first, thinking through all the special circumstances I needed to consider when arranging the seating seemed like a lot to comprehend, yet alone dive in and divide into specific methods. It took a lot of just writing and then going back and finding out what worked, what didn't, which classes the code that worked belonged, etc. I did find Runestone and W3 Schools very helpful to me in reminding me of the fundamentals of File.io programs as well as learning about continue statements. I also think visualizing the seating placements was something I began doing later on that helped me get a more concrete grasp of what the project was on. Overall, this was a challenging project for me but I'm very happy and relieved to be finished.
